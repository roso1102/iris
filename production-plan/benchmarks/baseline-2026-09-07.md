## Architecture evidence

- Scanned OCR returns plain text without word/line geometry; precise scanned bbox mapping is not currently possible.
- Pub/Sub page handling is non-idempotent because chunk IDs are random and push delivery is at-least-once.
- Document completion/summary logic depends on page completion order.
- Qdrant is a single `e2-small` VM without replica or documented restore evidence.
- Runtime service accounts have broad Firestore and GCS permissions.
- Rate limiting is per-instance memory and can be bypassed through horizontal scaling.
